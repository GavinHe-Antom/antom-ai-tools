- Interface: `com.alipay.iacqintegrationhub.channel.sdk.spi.callback.AcsUrlCallbackService`
- Signature: `AcsUrlCallbackResponse onlineBankUrlCallback(AcsUrlCallbackRequest request)`
- Java requirement: Optional; the SDK throws UnsupportedOperationException unless overridden.
- Platform capability: `ChannelSpiOperation.ONLINE_BANK_URL_CALLBACK`
- Platform endpoint: SDK contract only; no connected platform HTTP endpoint.
- Institution route key: This SPI does not select an institution destination route.

Online banking URL callback method.

SDK contract only, with no platform endpoint. Renaming or reusing the ACS URL does not connect an online banking callback.
