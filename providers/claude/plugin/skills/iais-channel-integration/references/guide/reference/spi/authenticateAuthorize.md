## Contract and platform availability

- Interface: `com.alipay.iacqintegrationhub.channel.sdk.spi.payment.PaymentService`
- Signature: `AuthenticateAuthorizeResponse authenticateAuthorize(AuthenticateAuthorizeRequest request)`
- Java requirement: Optional; the SDK throws UnsupportedOperationException unless overridden.
- Platform capability: `ChannelSpiOperation.AUTHORIZE`
- Platform endpoint: `POST /{channelCode}/channel/pay/authorize`; requires channel-module registration and an SPI bean.
- Institution route key: `authorize` (DomainControlConfig.pathMap)

Complete payment authorization after authentication in the two-call 3DS flow; this is separate from the initial pay operation.

Implement this method only when two-call 3DS is in scope. Its independent AuthenticateAuthorizeRequest is neither AuthorizeRequest nor PayRequest. It does not contain
env/paymentRedirectUrl, so do not copy field access from pay. Confirm how existing authentication information is carried in the mapping specification.
