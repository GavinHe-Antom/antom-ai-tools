# AuthenticateAuthorizeRequest

[Model index](README.md) · [SPI index](../spi/README.md)

`com.alipay.iacqintegrationhub.channel.sdk.spi.payment.request.AuthenticateAuthorizeRequest`

Authentication/authorization request passed by the authorize platform entry point to PaymentService.authenticateAuthorize. Modeled separately from PayRequest. Adapters handle authentication/authorization fields according to the channel protocol; similar fields are not a reason to call pay instead.
